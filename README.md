# Alternative Tuner for Windows

A guitar and bass tuner for any tuning: a Windows desktop app and a VST3 plugin.

**Download: [alternativetuner.com/download](https://alternativetuner.com/download)**, or from the [latest release](https://github.com/pejopar/alternative-tuner-releases/releases/latest):

| File | What it is |
| --- | --- |
| `AlternativeTuner-Setup.exe` | Installer: adds a Start menu entry |
| `AlternativeTuner-Portable.exe` | Single .exe, no install needed |
| `AlternativeTuner-VST3.zip` | VST3 plugin: unzip into `C:\Program Files\Common Files\VST3` |

Windows 10 or 11 (64-bit). The plugin needs a VST3 host (most DAWs).

It's free. If you like it, you can pay what you want to support development, at [alternativetuner.com/download](https://alternativetuner.com/download).

This repository only hosts the downloads. The source code is not public, and the software is not open source; see [LICENSE](LICENSE).
